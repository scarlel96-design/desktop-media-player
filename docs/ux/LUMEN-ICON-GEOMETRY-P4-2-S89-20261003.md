## 규칙 (총괄 지시 반영)

- 그리드 24, **코어 도형은 2.75~21.25 안**. 템플릿 `Path`의 `Stroke 1.5`(`Round` join)가 외곽을 사방 0.75 키우므로 **시각 = 코어 + 1.5**.
- `FillRule` 속성은 쓰지 않는다. EvenOdd 링은 path 맨 앞 `F0 `. 이번에 `F0`을 쓰는 것은 Subtitle과 Info 두 개다.
- 원과 둥근 모서리는 arc(A) 명령을 쓴다. 주석에 연속 하이픈은 쓰지 않는다. 각 경로는 닫힌 하위 경로만으로 구성된다(열린 하위 경로는 평평한 끝 처리가 달라질 수 있어 쓰지 않음).
- **선 요소 해석 확인**: 스펙의 "두께 1.5 호"는 `Stroke`가 1.5를 더하므로 코어 두께 0이 되어 그릴 수 없다. 그래서 **선 요소는 코어 두께 0.5의 링/막대 면**으로 그리고 시각 두께는 **2.0**이 된다(S88 FrameStep/Back과 같은 규칙). 스펙의 "1.5"는 "시각 약 2.0"으로 바뀐다. 이 편차를 Phase 4·5 스펙 Rev2에 반영한다.
- 겹치는 하위 경로의 방향은 모두 같게(시계 방향) 만들어 nonzero 채움에서 교차부가 비지 않게 했다(VolumeOff X 교차점 픽셀 확인).

## 경로 문자열 (`Lumen.Icon.*`, StreamGeometry에 그대로 사용)

### VolumeOn

스피커 본체(채움) + 호 2개. 호는 코어 두께 0.5 링 조각(시각 2.0). 스펙의 "호 1~2개" 중 2개.


### VolumeOff

## 구분이 필요한 항목 (렌더 확인 후보, 지금은 NOT EVALUATED)

- Screenshot과 FullscreenEnter는 둘 다 모서리 브래킷이다. 구분 수단은 크기(13×10 대 16.5×13)와 Screenshot의 중앙 점이다. 24 DIP에서 충분히 구분되는지는 Gate 스냅샷에서 본다. 부족하면 Screenshot을 다른 형태로 바꾸는 것을 제안한다.
- ThemeDark / ThemeLight / ThemeSystem이 한눈에 구분되는지는 Gate 항목이다.
- 시각 두께 2.0의 선은 Play/Pause 등 채움형 도형(시각 두께 약 3.5)보다 가늘다. 이는 의도한 위계(보조 아이콘이 더 가볍다)이며 렌더 확인 항목이다.

## 구현 메모

- 키는 `Lumen.Icon.<Name>`, 형식 `StreamGeometry`, Dark/Light 공통이므로 `Themes/Lumen.Icons.xaml` 한 곳에 둔다.
- 경로의 `A` 명령은 플래그를 `0`/`1`로 쓴 공백 구분 형식이며 WPF 경로 문법에서 유효하다. 문자열을 다시 서식할 때 숫자 앞의 부호와 `A`의 플래그 두 개(큰 호, 방향)를 바꾸지 않는다.
