# 화면 캡처 안내서 (사용자용) — Visual Gate 증거 수집

문서 전용. 코드·빌드 변경 없음. 근거: `VISUAL-GATE-GAP-TABLE-20261003.md` §4.
목적: 지금 화면이 어떻게 보이는지 사진/영상으로 남겨, UI 품질 판정에 쓸 증거를 모읍니다. **이 캡처는 합격 판정이 아니라 현재 모습을 기록하는 것**입니다. 잘 찍었는지 걱정하지 않으셔도 됩니다. 못 찍은 항목은 "못 함"이라고만 적어 주세요.

## 0. 시작 전 (2분)

1. 플레이어를 **새 폴더에 푼 최신 빌드**로 실행합니다. 어느 빌드인지 알 수 있게 **폴더 이름**(예: `dmp-windows-measure-...`)을 메모해 둡니다.
2. 영상 1개를 준비합니다(1~2분 이상, 소리가 있는 것). 자막이 있는 영상이 있으면 하나 더(5번 캡처용). 없으면 5번은 건너뛰어도 됩니다.
3. 창은 처음 켠 **기본 크기 그대로** 둡니다(1~6번).
4. 바탕화면의 개인 정보(알림, 다른 창)가 찍히지 않게, 플레이어 **창 하나만** 크게 보이게 하세요.

## 1. 사진 찍는 방법 (두 가지 중 쉬운 쪽)

**방법 A. 화면 전체 자동 저장 (가장 쉬움)**
- 키보드에서 `Win` 키를 누른 채 `PrtSc`(Print Screen) 키를 누릅니다. 화면이 잠깐 어두워지면 저장된 것입니다.
- 저장 위치: `내 PC > 사진(Pictures) > 스크린샷(Screenshots)`. 파일 이름은 자동으로 `Screenshot (번호).png`로 생깁니다.
- 노트북에서 `PrtSc`가 안 되면 `Fn` 키를 같이 눌러 보세요.

**방법 B. 플레이어 창만 오려 찍기**
- `Win` + `Shift` + `S`를 누르면 화면이 어두워지고 위에 작은 도구 막대가 뜹니다. 가운데 쪽 "창 모드"나 "사각형 모드"를 고르고 플레이어 창을 선택합니다.
- 찍은 것은 일단 클립보드에 복사됩니다. 오른쪽 아래에 뜨는 알림을 **클릭**하면 캡처 도구가 열리고, 거기서 `Ctrl+S`로 저장합니다(저장 위치: 사진 > 스크린샷 또는 원하는 폴더).
- 알림이 사라졌다면 방법 A를 쓰세요.

둘 중 아무거나 괜찮고, **한 번에 하나의 방법으로 통일**해 주세요.

## 2. 영상 찍는 방법 (5~10초)

**방법 A. Xbox Game Bar**
1. 플레이어 창을 **클릭해서 선택**한 상태에서 `Win` + `Alt` + `R`을 누르면 녹화가 시작됩니다(화면 한쪽에 작은 녹화 표시가 뜹니다).
2. 안내된 동작을 한 뒤 다시 `Win` + `Alt` + `R`로 끝냅니다. **총 5~10초**가 되게 합니다.
3. 저장 위치: `내 PC > 동영상(Videos) > 캡처(Captures)`.
4. 만약 아무 반응이 없으면 `Win` + `G`를 눌러 Game Bar를 열고 "캡처" 창의 둥근 녹화 버튼을 눌러 보세요. 그래도 안 되면 설정 > 게임 > Xbox Game Bar가 켜져 있는지 확인합니다.

**방법 B. 캡처 도구의 녹화 (Windows 11)**
- `Win` + `Shift` + `S` 도구 막대에서 비디오 아이콘을 고르고 플레이어 창 영역을 선택해 시작/종료합니다. 저장은 알림 클릭 후 저장.

영상이 어렵거나 안 되면 **영상은 "못 함"으로 적고 사진만 보내도 됩니다.**

## 3. 파일 이름 규칙

저장한 파일의 이름을 아래처럼 바꿔 주세요(마우스 오른쪽 > 이름 바꾸기, 또는 선택 후 `F2`).

`번호_장면_빌드폴더이름.png` 형태이며, 번호는 아래 표의 번호입니다. 폴더 이름이 길면 마지막 7자리 영문/숫자(커밋 번호)만 써도 됩니다.

예: `01_playing_7d92c06.png`, `08_video-seek-click_97c0360.mp4`

이름을 바꾸기 어려우면 **그냥 찍은 순서대로 보내고 채팅에 "1번부터 순서대로"라고 써 주세요.** 순서만 맞으면 됩니다.

## 4. 캡처 9종 (이 순서대로)

각 항목은 **재생 중 영상 하나로 이어서** 하면 편합니다. 한 동작 후 약 2초 쉬고 찍으세요.

| 번호 | 파일 이름 | 장면과 순서 | 기대하는 장면 (이런 모습이면 맞게 찍은 것) |
|---|---|---|---|
| 1 | `01_playing` | 영상을 열어 재생합니다(`Ctrl+O`로 열기). 마우스를 **플레이어 아래쪽 컨트롤 막대 위**로 가져가 막대가 보이는 상태에서 사진. | 영상 + 아래 컨트롤 막대(진행 바, 시간, 버튼들)가 모두 보임. |
| 2 | `02_paused` | `Space`(스페이스바)로 일시정지하고 사진. | 일시정지 상태에서 막대가 보임. 재생/일시정지 버튼 모양이 함께 보여야 함. |
| 3a | `03a_chrome-hidden` | 다시 `Space`로 재생. **마우스를 영상 한가운데로 옮기고 움직이지 말고** 약 3초 기다림. 막대가 사라진 상태에서 사진. | 컨트롤 막대가 사라지고 영상만 보임. 아래쪽에 **다른 색의 띠**가 보이는지도 그대로 두기. |
| 3b | `03b_chrome-shown` | 마우스를 살짝 움직여 막대가 다시 나타난 직후 사진. | 막대가 다시 보임. |
| 4a | `04a_hover-play` | 마우스를 **재생 버튼 위에 올려놓고** 사진(클릭하지 않음). | 마우스가 올라간 버튼의 색 변화가 보임. |
| 4b | `04b_press-play` | 재생 버튼을 **마우스로 누른 채** 사진(누른 채로 찍기 어렵다면 "못 함"). | 눌린 버튼 모양. |
| 4c | `04c_focus-tab` | 키보드 `Tab`을 몇 번 눌러 버튼 하나가 선택된 상태에서 사진. | 선택된 버튼에 테두리가 보이는지(안 보여도 그대로 찍기). |
| 4d | `04d_disabled-prev-next` | 재생 목록이 영상 1개일 때 이전/다음 버튼이 흐려진 상태에서 사진. | 비활성(흐린) 이전/다음 버튼. |
| 5a | `05a_osd-volume` | 영상 위에서 **마우스 휠을 한 칸** 돌려 볼륨을 바꾼 직후 사진. | 화면 가운데에 볼륨 글자가 잠깐 보임. |
| 5b | `05b_subtitle` | (자막 영상이 있을 때만) 자막이 보이는 장면 사진. | 자막 글자가 영상 위에 보임. |
| 6 | `06_fullscreen` | `F11`(또는 `F`)로 전체화면. 마우스를 움직여 막대가 보일 때 사진. `Esc`로 나옴. | 전체화면에서 막대가 보임. |
| 7 | `07_narrow-window` | 창 가장자리를 끌어 **가능한 가장 좁게** 줄이고 사진. 막대가 보이게 마우스를 아래에 둠. | 오른쪽 버튼이 잘리거나 겹치는지 보임. |
| 8 | `08_video-seek-click` | **영상(5~10초)**. 녹화 시작 → 재생 중 진행 바의 **빈 곳을 한 번 클릭**(동그란 손잡이가 아닌 곳) → 2~3초 → 재생/일시정지 버튼을 한 번 클릭 → 목록 버튼(≡)을 눌러 재생 목록 열기 → 다시 닫기 → 녹화 종료. | 클릭할 때 막대와 화면이 어떻게 반응하는지가 영상에 담김. |
| 9 | `09_theme-dark` / `09_theme-light` / `09_theme-system` | 오른쪽 버튼 줄의 `◐` 버튼을 눌러 테마를 바꿀 때마다 사진(3번 누르면 한 바퀴). | 밝은/어두운 화면이 각각 보임. |

사진은 합쳐서 **약 14장**, 영상 1개입니다. 번호가 하위 문자로 나뉜 것도 모두 1세트입니다. 시간이 없으면 **1, 2, 3a, 3b, 8**만 먼저 보내 주세요(가장 중요한 순서).

## 5. 보내기

1. 사진과 영상을 채팅에 첨부합니다(여러 개 한꺼번에 가능).
2. 같이 적을 것: 사용한 **빌드 폴더 이름**, PC 모니터 해상도(모르면 생략), 못 찍은 항목 번호.
3. 영상이 커서 첨부가 안 되면 "영상 용량 큼"이라고만 적어 주세요. 대안을 안내드립니다.

## 6. 주의

- 사진에 **개인 정보**(다른 창의 이메일, 알림 등)가 보이면 그 사진은 보내지 말고 다시 찍어 주세요.
- 키 이름이 제 설명과 다르거나 기능이 안 되면 **그대로 "안 됨"**이라고 알려 주세요. 그것도 중요한 정보입니다.
- 이 캡처로 합격/불합격이 바로 정해지지 않습니다. 현재 모습을 기록해 격차 표의 "증거 부족" 항목을 채우는 용도입니다.
- 이전 로그 측정 안내(`WINDOWS-MEASUREMENT-GUIDE-*`)와 별개이며, `spike.log`는 이번엔 필요 없습니다.
