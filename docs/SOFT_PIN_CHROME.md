# Soft Pin Chrome (S35 Soft)

Shell Soft: Ctrl+Shift+H toggles chrome pin Soft.
Pin On: BottomChrome always visible Soft; auto-hide timer Soft stop (via ShouldPauseAutoHide).
Pin Off: existing ShowChrome/ArmAutoHide Soft resume. OSD Soft: Chrome pinned / Chrome unpinned.
No persist. Soft != Windows PASS. KI-022/024 WINDOWS PENDING.
